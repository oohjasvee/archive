# **App Name**: Astral Portfolio

## Core Features:

- Hero Section: Display name and professional tagline.
- About Section: Provide a brief introduction and overview.
- Education Section: List educational background with relevant details.
- Experience/Projects Section: Showcase professional experience and projects.
- Skills Section: List relevant skills with visual indicators (e.g., progress bars).
- Positions of Responsibility Section: Detail leadership roles and responsibilities.
- Resume/LinkedIn/Email Links: Provide links to resume (PDF), LinkedIn profile, and email.

## Style Guidelines:

- Background color: Dark gray (#121212) to provide a modern, sophisticated feel.
- Primary color: Light purple (#A8B4FF) to act as the main highlight color for text and interactive elements; this will contrast well with the dark background and create a modern aesthetic.
- Accent color: Violet (#7C4DFF) for buttons and hover effects to complement the light purple; since violet is the median color in the purple gradients, it will draw attention to call-to-action items without clashing.
- Body and headline font: 'Inter' for a clean, modern, sans-serif typeface.
- Single-page layout with smooth scrolling to sections.
- Use glassmorphism-style cards with subtle frosted glass effect for sections.
- Subtle hover animations for buttons and links.
